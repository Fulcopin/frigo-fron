## Base de Datos - Vista SQL

```sql
SELECT 
    FormID,
    TemplateID,
    TemplateVersion,
    LEN(TemplateSnapshot) as SnapshotSize,
    CreatedAt
FROM FilledForms
ORDER BY FormID DESC;
```

**Resultado:**

```
┌────────┬────────────┬─────────────────┬──────────────┬─────────────────────┐
│ FormID │ TemplateID │ TemplateVersion │ SnapshotSize │ CreatedAt           │
├────────┼────────────┼─────────────────┼──────────────┼─────────────────────┤
│ 124    │ 9          │ 03-01           │ 2847         │ 2025-12-15 11:15:00 │
```
