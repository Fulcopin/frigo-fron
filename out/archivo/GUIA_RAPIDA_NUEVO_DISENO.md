## 🎨 **VARIABLES CSS PARA USAR**

En tus archivos CSS, puedes usar:

```css
/* Colores */
var(--primary)        /* Azul #035b8d */
var(--secondary)      /* Gris #2b2b2b */
var(--border)         /* Gris claro #e1e1e1 */
var(--text)           /* Texto #2b2b2b */

/* Sombras */
var(--shadow-sm)      /* Sombra pequeña */
var(--shadow-md)      /* Sombra mediana */
var(--shadow-lg)      /* Sombra grande */
```
