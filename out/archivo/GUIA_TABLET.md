# 🎯 GUÍA RÁPIDA - TABLET UROVO P8100 4G

## Header Colapsable (Frigolab San Mateo)

### Botón de Control
- **Ubicación:** Esquina superior derecha
- **Colapsado:** Botón VERDE - "Mostrar Encabezado" ⬇️
- **Expandido:** Botón AZUL - "Ocultar Encabezado" ⬆️

### Estados
1. **Colapsado (por defecto):** 
   - Altura: 60px
   - Muestra: 📋 Título | Código v1 | Fecha

2. **Expandido:**
   - Altura: 120px
   - Muestra: Logo completo + Toda la información

## Acordeones de Secciones

Cada sección tiene un header clicable:
- 📋 **Información General** (X campos)
- 📝 **Secciones personalizadas** (X campos)
- 📊 **Tablas dinámicas** (X filas)
- ✍️ **Firmas y Aprobaciones** (X firmas)

**Cómo usar:**
- Clic en el header para expandir/colapsar
- Flecha ▼ = colapsado
- Flecha ▲ = expandido

## Autoguardado

### Indicadores
- 💾 Amarillo: "Guardando..."
- ✅ Verde: "Guardado"
- ⚠️ Rojo: "Sin guardar"

### Cuándo se guarda
- ⏱️ Cada 30 segundos automáticamente
- 🚪 Al salir de la página
- 📱 Al cambiar de aplicación
- ❌ Al presionar "Cambiar Plantilla"

## Teclado Virtual

### Comportamiento Automático
- El formulario hace scroll para mostrar el campo activo
- Campo enfocado se resalta en amarillo
- Espacio extra al final para no tapar campos

### Tips
- Usar teclado flotante para mejor visualización
- El scroll automático centra el campo activo
- Tocar fuera del campo para cerrar teclado

## Clics Accidentales

### Protección
- ⚠️ Confirmación antes de salir con cambios
- 💾 Datos guardados automáticamente como borrador
- 🔄 Recuperación al volver a abrir

## Orientación

### Horizontal (landscape)
- Mejor para tablas anchas
- 3 columnas en formularios
- Header más compacto

### Vertical (portrait)
- Mejor para formularios largos
- 1-2 columnas
- Más espacio para teclado
